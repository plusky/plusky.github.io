# plusky.github.io

Source of the personal site at https://plusky.github.io/, built with Hugo 0.164 (standard edition).
Posts are page bundles: `content/posts/<post>/index.md` with their figures under `fig/`.

## Build and preview

    make serve            # live preview with drafts at http://127.0.0.1:1313
    make all              # figures, checks, strict build, link and leak checks
    make shots PAGE=/posts/<post>/   # screenshots at 400 and 1280 px, light and dark, drafts included, in .preview/shots/

`make build` is the same strict build CI runs (`--panicOnWarning`); any warning fails it.
Use another Hugo binary with `make HUGO=/path/to/hugo ...`.

## Figures and facts

- Figures are SVGs generated by `make figures`, the charts from `data/fig/<id>.json` and the diagrams
  without a data file; the output is committed.
  `figures/README.md` has the rules every SVG follows; `make preview-figures` shows them all on one page.
- `make fresh` rebuilds the figures and fails if a committed one differs from its rebuild; it does not
  notice files left by a removed generator, so delete those with the generator.
- Every number a post quotes is in `data/facts.json`; other numbers that are fine to write (with a
  reason) go in `data/facts_allow.txt`.

## Checks

- `make check`: `tools/check_svg.py` (the SVG rules), `tools/check_facts.py` (numbers in posts and figure
  descriptions), `tools/check_leaks.py` (internal names, hosts, addresses; extra local terms in
  `~/.config/plusky-site/denylist.txt`).
- `make linkcheck-internal`: every link and fragment in `public/` resolves, nothing loads from another host.
- `make linkcheck`: outbound links still answer; slow and polite, cached in `.cache/links.json`, local only.
- The checks with `--self-test` test themselves.
- Optional hook running the leak, SVG and facts checks before each commit:
  `git config core.hooksPath .githooks`.

## Publishing

A push to `main` runs `.github/workflows/pages.yml`: it installs the pinned Hugo (checksum in the
workflow), runs `make fresh`, the checks, the strict build, the leak check on `public/` and the internal
link check, then deploys to GitHub Pages. Pages must be set to "GitHub Actions" as its source. To move to a
new Hugo release, update `HUGO_VERSION` and `HUGO_SHA256` together, from the release's checksums file.

## Data and licence

The files under `data/` are extracts from private experiment records; the tooling that produced them is not
part of this repository, so `make figures` rebuilds the figures from the JSON files but cannot rebuild the
JSON files themselves.
