1. The benchmark server ran llama-server with --ctx-size 262144 and --parallel 8.
  2. It divided the context into 8 equal slots of 32,768 tokens; each request got one slot.
  3. The script keeps 2,048 tokens of a slot for the three replies.
  4. Two real prompts against one slot:
    1. 32.3k tokens: inside the slot, but in the part kept for the replies. The request failed.
    2. 35.3k tokens: 2.5k tokens over the slot. The request failed.
  5. The script cuts the prompt by characters, assuming 2.5 characters per token. Real prompts measure a median of 2.28 characters per token, so they hold about 10% more tokens than it estimates (2.5 / 2.28 = 1.10).
